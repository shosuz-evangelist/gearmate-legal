# GearMate の法務ページ

App Store の審査に要るページを GitHub Pages で出すためのリポジトリ。

- **プライバシーポリシー** — `privacy.md`。App Store Connect の URL 欄と、
  アプリ内と Paywall のリンク先に使う
- **利用規約** — 自前で用意していない。Apple の標準の規約
  <https://www.apple.com/legal/internet-services/itunes/dev/stdeula/> をそのまま指す

アプリ本体は別のリポジトリにある。ここには法務のページしか置かない。
